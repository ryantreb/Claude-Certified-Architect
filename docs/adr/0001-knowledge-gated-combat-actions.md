# Resolve combat actions through knowledge gates

Combat records the player's tactical action and target as an unresolved Action Intent, then uses a region-driven Knowledge Gate to determine its outcome; a correct answer applies the effect and spends its resources, while a wrong answer fails without spending resources and passes the turn. This separates tactical choice from certification-question selection, keeps recall region-driven, and makes the player's answer causally responsible for combat while allowing an optional, settings-controlled d20 resolution step.
